# Rock & Roll Star Chronicle

Static prototype for a music-history website idea, ready for GitHub Pages.

The sample artist is Freddie Mercury. The page presents a temporal list of well-known Queen/Freddie-related hits. Selecting a song updates the story panel with backstory, career context, personal context, album, writer credit, and historical significance.

Open `index.html` in a browser, or run a small local server from this folder:

```bash
python3 -m http.server 8094
```

Then visit:

```text
http://127.0.0.1:8094
```

To adapt the prototype for another artist, edit the `artists` array in `script.js`.
